# Design note — Phase 5.3, study 3: the factor zoo

Status: **draft, awaiting approval.**

## Question

Hundreds of published characteristics are claimed to predict the cross-section of stock
returns. Two papers ask how much of this survives:

- **Harvey, Liu and Zhu (2016, *RFS*):** with so many tests, the usual t > 2 threshold is too
  low. They propose about t > 3 and multiple-testing corrections.
- **McLean and Pontiff (2016, *JF*):** long-short returns fall after the original sample ends,
  and fall further after publication, but they do not disappear.

Chen and Zimmermann's Open Source Asset Pricing (OSAP) replicates about 200 predictors with
public code. This allows both questions to be asked on one consistent dataset.

**Hypotheses, stated before running:**

- **H1 (multiple testing, descriptive).** In each predictor's original sample, report how many
  are significant at 5 % under each rule:
  - single test, |t| > 1.96;
  - t > 3.0 (HLZ);
  - Holm, Benjamini–Hochberg and Benjamini–Yekutieli adjusted p-values.

  No direction is claimed; the counts are the result.
- **H2 (McLean–Pontiff replication).** Average long-short returns are lower after the original
  sample ($\beta_{post\text{-}sample}<0$) and lower again after publication
  ($\beta_{post\text{-}pub}<\beta_{post\text{-}sample}$). The test is a panel regression with
  predictor fixed effects and standard errors clustered by month.
- **H3 (not zero).** The post-publication return of an equal-weighted composite of all
  predictors is still positive.

An honest null result is a valid result and is reported as such.

### New dependency: `pyarrow`

**Why:** release 2026.10 publishes the returns **only as Parquet**, and pandas needs `pyarrow`
to read Parquet. There is no CSV version on the official channels; older CSV releases are
retired.

**Proposal:**

- `pyarrow` becomes an **optional extra** (`qrlab[parquet]`) and a dev dependency, so that CI
  and tests can write synthetic Parquet files. The core library and the future desktop app do
  not need it.
- The study kind imports it only when it reads the file. If it is missing, the kind says how
  to install it.

**Alternatives considered:**

- `fastparquet`: less used, and pandas support for it is ending.
- Asking the Hugging Face API for converted data: the raw file would no longer be the stored
  original.

This needs your explicit approval.

## Method

**Universe:**

- **Main:** predictors with `Cat.Signal = Predictor` and `Predictability in OP = 1_clear`.
- **Robustness:** `1_clear` and `2_likely` together.

These are the two configurations, both fixed now.

**Phases of each predictor's months:**

| Phase | Months |
|---|---|
| pre-sample | before January of `SampleStartYear`; excluded |
| in-sample | `SampleStartYear`-01 to `SampleEndYear`-12 |
| post-sample | from `SampleEndYear + 1`-01 up to and including `Year`-12 |
| post-publication | from `Year + 1`-01 on |

`Year` is the publication year. Only the year is known, so post-publication starts the
following January. This is conservative: months in the publication year count as
post-sample. It is a stated deviation from McLean–Pontiff, who use the publication date.

**H1:**

- For each predictor, the in-sample mean return is tested against zero with a Newey–West
  t-statistic (6 lags) and a two-sided p-value.
- Counts are reported under:
  - |t| > 1.96;
  - t > 3.0;
  - Holm, BH and BY at 5 % across the predictors of the configuration.
- For context, the same counts are reported for the post-publication period. They are not
  part of H1.

**H2:**

- Pooled regression
  $r_{i,t}=\alpha_i+\beta_{ps}\,\text{PostSample}_{i,t}+\beta_{pp}\,\text{PostPub}_{i,t}+\varepsilon_{i,t}$,
  with predictor fixed effects (within transformation) and standard errors clustered by month.
- **Decay** is $\beta/\bar r_{in}$, where $\bar r_{in}$ is the pooled in-sample mean. This is
  the McLean–Pontiff percentage.
- **Tests:**
  - $\beta_{ps}<0$;
  - $\beta_{pp}<0$;
  - $\beta_{pp}-\beta_{ps}<0$, a linear combination tested with the clustered covariance.

  All tests are two-sided.

**H3:**

- Each month, average the returns of the predictors that are post-publication in that month.
- Test the mean of that composite against zero with a Newey–West t-statistic (6 lags).
- The same composite is reported for the in-sample and post-sample phases.

**Missing values:**

- Each predictor's series starts and ends where OSAP has data.
- Gaps inside a series are counted and reported, and those months are left out of that
  predictor's statistics. They are not filled.
- If more than 1 % of a predictor's months are missing inside its range, the run stops: that
  would point to a data problem.

## Implementation

- **`data.open_asset_pricing`** (data layer):
  - source `osap`, terms and URLs pinned to the revision;
  - `download_osap` through the raw store;
  - `parse_signal_doc`: strict, with required columns and allowed categories;
  - `parse_long_short_returns`: Parquet, percent to decimal, month-end dates, strict column
    checks.
  - Tests write small synthetic Parquet and CSV files.
- **`stats.panel.fixed_effects_ols`:**
  - entity fixed effects by the within transformation;
  - standard errors clustered by an explicit grouping, with the small-sample correction of
    statsmodels and degrees of freedom adjusted for the absorbed effects;
  - cross-checked against statsmodels OLS with dummy variables;
  - a new module, needed because no clustered or panel estimator exists yet.
- **`studies.factor_zoo`** (pure functions):
  - phase classification;
  - per-predictor tests and counts;
  - the panel regression;
  - the composites;
  - the tables.
- **Experiment kind `study_factor_zoo`:**
  - inputs: the returns file and the signal documentation;
  - parameters: categories, HAC lags, the HLZ threshold, significance and the sample end;
  - outputs: tables tagged `in_sample` (original-sample tests) or `out_of_sample`
    (post-sample and post-publication results, regression, composites), an HTML report and
    the record.
- **Written report** `docs/studies/03-factor-zoo.md`, written after the run with the actual
  numbers.

## Risks

- **Not independent of the original papers.** OSAP's signs come from the original papers, so
  in-sample t-statistics are biased upward by construction. That is part of the question, and
  the report says so.
- **The publication year is a proxy.** It is a coarse marker of when the public learned of a
  predictor: working papers circulate earlier. The bias goes against finding a decay at the
  publication date.
- **Overlap.** Predictors overlap heavily and are correlated. Clustering by month handles
  cross-sectional correlation in H2. BY is the multiple-testing correction that remains valid
  under arbitrary dependence.
- **No costs.** These are gross, paper long-short returns, so "survives" means statistically,
  not net of trading costs. Chen and Velikov (2023) study costs; that is recorded in
  `docs/IDEAS.md`.
