# Design note — Phase 2.2 `qrlab.stats`

Status: **approved 2026-11-10; implemented.** Deviations, if any, are listed at the end.

## Goal

Statistical inference for financial time series. Three uses:

- regressions whose standard errors are robust to heteroskedasticity and autocorrelation
  (returns are rarely iid);
- the factor exposures of a portfolio or fund (CAPM, Fama–French 3 and 5 factors, momentum),
  with robust standard errors;
- confidence intervals for any statistic of dependent data through a block bootstrap.

These feed the X-ray report (M2), the risk models (3.1) and later inference (5.1).

## Scope

| Module | Contents |
|---|---|
| `stats/regression.py` | `ols` with `CovType` (non-robust, White HC1, Newey–West HAC) wrapping statsmodels; `newey_west_lags` rule |
| `stats/rolling.py` | `rolling_ols`: trailing windows only, labelled by window end |
| `stats/factors.py` | `FactorModel` (CAPM, FF3, FF5, FF3+momentum, FF5+momentum) and `factor_exposures` |
| `stats/bootstrap.py` | `stationary_bootstrap` (Politis and Romano, 1994) with an explicit seeded generator |

Two small additions outside `stats`, needed by factor exposures:

1. **`data.ken_french`**: add the **Developed** and **Europe** factor files (3 factors,
   5 factors, momentum). They have the same format as the US files (checked on the live files
   on 2026-11-10; files deleted afterwards). The momentum column is called `WML` instead of
   `Mom`. For a European investor in global ETFs these are more relevant than the US factors.
2. **`core.returns.convert_return_currency`**: re-expresses returns in another currency with
   dated exchange rates, $1 + r^{USD}_t = (1 + r^{EUR}_t)\,S_t / S_{t-1}$, where $S$ is USD per
   EUR. French factors are in USD. Regressing EUR returns on USD factors would mix currency
   moves into the betas, so the currencies must match, and a mismatch raises.

**Layering:** `stats` keeps `ALLOWED = {"core"}`. Factor data arrives as a DataFrame, so
`stats` never imports `data`.

## 1. Regression

```python
class CovType(Enum):
    NONROBUST = "nonrobust"  # classical OLS
    HC1 = "hc1"  # White, small-sample scaled
    HAC = "hac"  # Newey-West, Bartlett kernel


def ols(
    y: pd.Series,
    x: pd.DataFrame,
    *,
    add_intercept: bool,
    cov_type: CovType,
    hac_lags: int | None,
) -> OlsResult: ...


def newey_west_lags(n: int) -> int: ...  # floor(4 (n/100)^(2/9)); a documented rule, never implicit
```

- **Inputs:** `y` and `x` have identical indexes (no silent alignment) and no NaN.
- **Arguments:** `add_intercept` and `cov_type` are required. `hac_lags` is required for HAC
  and forbidden otherwise.
- **`OlsResult`** carries params, standard errors, t-statistics, p-values, confidence
  intervals, $R^2$, adjusted $R^2$, the number of observations, the covariance type and the
  lags.
- **Refused designs:**
  - singular or collinear regressors raise, with the rank of $X$ reported;
  - too few observations ($n \le k$) raise;
  - a constant column together with `add_intercept=True` raises.
- **HAC settings:**
  - Bartlett kernel;
  - the statsmodels small-sample correction choice is fixed and documented;
  - the result is cross-checked against an independent NumPy implementation of the
    Newey–West formula in the tests.

## 2. Rolling regression

`rolling_ols(y, x, *, window, add_intercept, cov_type, hac_lags)`:
- the estimate labelled $t$ uses observations $t - \text{window} + 1 \dots t$ only, so it is
  available after $t$ — no look-ahead;
- the first `window − 1` dates have no estimate.

## 3. Factor exposures

```python
class FactorModel(Enum):
    CAPM = ("Mkt-RF",)
    FF3 = ("Mkt-RF", "SMB", "HML")
    FF5 = ("Mkt-RF", "SMB", "HML", "RMW", "CMA")
    FF3_MOM = ("Mkt-RF", "SMB", "HML", "MOM")
    FF5_MOM = ("Mkt-RF", "SMB", "HML", "RMW", "CMA", "MOM")


def factor_exposures(
    excess_returns: pd.Series,
    factors: pd.DataFrame,
    *,
    model: FactorModel,
    periods_per_year: float,
    cov_type: CovType,
    hac_lags: int | None,
    momentum_column: str,
) -> FactorResult: ...
```

- **Inputs:**
  - `excess_returns` are the portfolio's returns minus the factor file's `RF`, in the
    **factors' currency**;
  - `factors` must contain the model's columns; `momentum_column` maps `MOM` to `Mom` (US) or
    `WML` (Developed and Europe);
  - indexes must be identical.
- **`FactorResult`:**
  - alpha per period and annualised (arithmetic, × `periods_per_year`);
  - betas, standard errors, t-statistics and $R^2$, plus the model, the number of
    observations and the covariance used.
- **No significance labels.** The result never states that an alpha is significant: it
  reports the t-statistic and p-value. Multiple-testing corrections come in 5.1.

## 4. Stationary bootstrap

```python
def stationary_bootstrap(
    data: pd.Series | pd.DataFrame,
    statistic: Callable[[np.ndarray], float],
    *,
    mean_block_length: float,
    n_resamples: int,
    confidence: float,
    rng: np.random.Generator,
) -> BootstrapResult: ...
```

- **Resampling:** blocks of geometric length (mean `mean_block_length`) start at random
  positions and wrap around the end (circular). Politis and Romano (1994).
- **Explicit choices:**
  - the generator is required, so results are reproducible and there is no hidden global
    seed;
  - the block length is explicit; automatic selection (Politis–White 2004) is recorded in
    `IDEAS.md`.
- **Interval:** percentile interval, with the method named in the result. The full resample
  distribution is kept for diagnostics.
- **Rows:** for frames, whole rows are resampled together, which preserves the cross-section.

## Hand-calculated and known-answer tests

| Case | Expected |
|---|---|
| OLS of y = (2, 3, 5) on x = (1, 2, 3) with intercept | β = 3/2, α = 1/3, residuals (1/6, −1/3, 1/6), SSR = 1/6 |
| Classical standard errors (same) | se(β) = √(1/6 ÷ 2) = 0.288675; se(α) = 0.623610 |
| Newey–West lag rule | n = 120 → 4; n = 240 → 4 |
| Currency: EUR return 1 %, USD per EUR 1.10 → 1.111 | USD return 1.01 × 1.01 − 1 = 2.01 % |
| Bootstrap, block length ≥ 10⁹ | every resample is a rotation, so every resampled mean equals the sample mean exactly |
| Bootstrap, block length 1 | equivalent to the iid bootstrap (blocks of length 1) |

**Known-answer simulations (seeded):**
- **Factor model:** $y = 0.002 + 1.1\,MKT + 0.3\,SMB + \varepsilon$ with AR(1) errors
  ($\rho = 0.5$).
  - The estimates must be close to the truth.
  - Over 400 simulations, the 95 % Newey–West interval for the market beta must cover the true
    value 91–98 % of the time.
  - The non-robust interval must cover it less often. This shows why HAC is the default
    recommendation, and it is stated in the docstrings.
- **Bootstrap:** the 95 % interval for the mean of iid normal data covers the true mean
  92–98 % of the time (seeded). For an AR(1) series, the interval from the stationary bootstrap
  is wider than the iid one.

## Cross-checks

- statsmodels for every covariance type;
- an independent NumPy Newey–West implementation;
- `rolling_ols` checked against fitting each window separately;
- `factor_exposures` checked against `ols` on the same columns.

## Edge cases

Empty or too short series, NaN, misaligned indexes, collinear factors, a missing factor
column, `hac_lags` given without HAC, a negative or non-integer lag, `window` < number of
regressors + 2, `mean_block_length` < 1, `n_resamples` < 100, a currency mismatch between
returns and factors.

## Risks

| Risk | Mitigation |
|---|---|
| Overstated significance from iid standard errors | HAC available and recommended; simulation shows the difference |
| Currency mismatch between returns and factors | Explicit conversion function; same currency required and documented |
| Look-ahead in rolling estimates | Trailing windows only, labelled by window end; test |
| Lag and block-length choices driving results | Always explicit, reported in the results |
| Data mining across factor models | Results carry the model and the number of observations; multiple testing in 5.1 |

## New dependencies

None (statsmodels and SciPy are already runtime dependencies).

## Deviations found during implementation

- **Coverage simulation design.** With iid regressors, autocorrelated errors alone barely
  affect classical standard errors, so the simulation uses a persistent regressor *and*
  persistent errors (AR(1) with coefficient 0.7 for both, n = 240, 400 runs). Measured 95 %
  coverage: **classical 75 %, Newey-West with the rule-of-thumb 4 lags 88 %**. HAC is much
  better but still below 95 % with this much persistence: lag choice matters and results
  report it. The test asserts classical < 85 % and HAC in [85 %, 98 %].
- **Rolling results** contain only dates with a full window (no NaN rows).
- **`momentum_column`** is required (`"Mom"` or `"WML"`) for momentum models and must be
  `None` otherwise, instead of being derived from the data.
- **Example:** `examples/factor_exposures.py` converts a synthetic EUR fund to USD with
  `convert_return_currency`, recovers its loadings (market 0.944 vs 0.95 true, size 0.200 vs
  0.20, momentum -0.097 vs -0.10) and bootstraps its mean excess return (integration test).
- **International factors** were verified on the live files (temporary folder, deleted):
  monthly data from July 1990 to September 2026 (momentum from November 1990) and annual
  sections, no missing values. International daily files exist but are not included.
