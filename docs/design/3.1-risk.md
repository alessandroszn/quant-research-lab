# Design note — Phase 3.1 `qrlab.risk`: risk models

Status: **approved 2026-11-11.** Deviations, if any, are listed at the end.

## Goal

Portfolio risk models that later phases build on: stress tests (3.2), projections (3.3) and
optimisation (4.x).

- **Covariance estimators:** sample, EWMA, Ledoit–Wolf shrinkage.
- **Risk decomposition:**
  - marginal and component contributions to volatility and to expected shortfall;
  - a factor risk model;
  - the effective number of bets, deferred from 2.4, added as a health check.
- **VaR/ES methods** beyond the historical and normal ones of 1.4: Cornish–Fisher and filtered
  historical simulation.
- **VaR backtesting:** Kupiec and Christoffersen tests on out-of-sample forecasts.

Every number is a one-period figure at the frequency of the input returns. It is annualised
only with an explicit `periods_per_year`.

## Inputs and conventions

- **Asset returns:** a `pandas.DataFrame` of **simple** returns, one column per asset, on a
  validated index (phase 1.1). A portfolio's return is $w^\top r$ only for simple returns, so
  log returns are refused through an explicit `kind` parameter.
- **Missing values:** an explicit `missing` parameter:
  - `"raise"` (the safe choice);
  - `"drop_rows"`: drops any date with a missing value, and the number of dropped rows is
    reported.

  Pairwise-complete covariance is **not** offered, because it can give a matrix that is not
  positive semi-definite.
- **Weights:** a `pandas.Series` by asset, with the same labels as the returns.
  - Weights must be finite.
  - They are not required to sum to 1, so a sub-portfolio or long-short weights are allowed.
    The sum is reported.
- **Factor returns** come from the caller (for example Ken French factors from `data`); `risk`
  does not load data. Asset and factor returns must share the same index; nothing is aligned
  silently. When factors are excess returns, the caller passes excess asset returns.
- **Loss sign:** VaR and ES are positive losses, as in 1.4.

## Covariance estimators

All three return a `CovarianceEstimate`:

- `matrix`: a DataFrame;
- `estimator`: the name;
- `n_obs` and `dropped_rows`;
- the parameters used (λ, shrinkage intensity);
- a positive semi-definiteness check (smallest eigenvalue ≥ −1e-12 × the largest, else raise).

| Estimator | Definition |
|---|---|
| Sample | $\hat\Sigma = \frac{1}{T-1}\sum_t (r_t-\bar r)(r_t-\bar r)^\top$ |
| EWMA | $\hat\Sigma = \sum_{k=0}^{T-1} \omega_k\, \tilde r_{T-k}\tilde r_{T-k}^\top$, $\omega_k = \frac{(1-\lambda)\lambda^k}{1-\lambda^T}$ (weights sum to 1); $\lambda$ required; `demean` required: `False` (RiskMetrics, zero mean) or `True` (sample mean) |
| Ledoit–Wolf | $\hat\Sigma = \delta\, \mu I + (1-\delta) S$, with $\mu = \operatorname{tr}(S)/N$ and the optimal intensity $\delta \in [0,1]$ of Ledoit and Wolf (2004, *J. Multivariate Analysis*), estimated in closed form; $\delta$ reported |

- The Ledoit–Wolf $S$ uses the $1/T$ normalisation of the paper. The paper and scikit-learn
  define it so.
- The constant-correlation target (Ledoit and Wolf 2004, *J. Portfolio Management*) goes to
  `docs/IDEAS.md`.

## Risk decomposition

- **Volatility:** $\sigma_p = \sqrt{w^\top\Sigma w}$.
  - The marginal contribution is $\text{MCR}_i = (\Sigma w)_i / \sigma_p$.
  - The component contribution is $\text{CCR}_i = w_i\,\text{MCR}_i$.
  - Components sum to $\sigma_p$ exactly (Euler); percentages sum to 1.
  - A zero-volatility portfolio raises: contributions are undefined.
- **Historical ES:**
  - The tail is the same as `metrics.historical_es`: the worst $m = T(1-\alpha)$ periods, the
    last one with a fractional weight.
  - The component is $-\frac{1}{m}\sum_{t \in \text{tail}} \theta_t\, w_i r_{i,t}$, where
    $\theta_t$ is 1 or the fractional weight.
  - Components sum to the historical ES exactly.
  - Ties in the portfolio loss are broken by date, so the result is deterministic.
- **Normal ES:** the component is
  $-w_i\mu_i + \frac{w_i(\Sigma w)_i}{\sigma_p}\,\frac{\varphi(z_\alpha)}{1-\alpha}$.
  Components sum to the parametric ES of 1.4.
- **Factor risk model:**
  - Each asset is regressed by OLS on the factors (`stats.ols`, an intercept included):
    $r_i = a_i + B_i^\top f + e_i$.
  - Then $\Sigma = B\,\Sigma_f B^\top + D$:
    - $\Sigma_f$ comes from a covariance estimator chosen explicitly;
    - $D$ is diagonal, the residual variances with `ddof = 1 + number of factors`.
  - The portfolio variance splits into a factor part and a specific part.
  - The factor contribution of factor $k$ is $(B^\top w)_k\,(\Sigma_f B^\top w)_k / \sigma_p$,
    and the factor and specific contributions sum to $\sigma_p$.
  - $R^2$ and the number of observations are reported per asset.
- **Effective number of bets** (Meucci 2009):
  - $\Sigma$ is decomposed into principal portfolios.
  - $p_k$ is the share of portfolio variance from principal portfolio $k$.
  - The result is $\text{ENB} = \exp(-\sum_k p_k \ln p_k)$, which runs from 1 to $N$.
  - The result depends on the choice of principal components. The minimum-torsion version
    (Meucci et al. 2015) is listed in `docs/IDEAS.md`.

## VaR/ES methods (single return series)

| Method | Definition |
|---|---|
| Historical, normal | existing `metrics.risk` functions, reused |
| Cornish–Fisher VaR | $z_{cf} = z + \frac{(z^2-1)S}{6} + \frac{(z^3-3z)K}{24} - \frac{(2z^3-5z)S^2}{36}$, with $z = \Phi^{-1}(1-\alpha)$; sample skewness $S$ and excess kurtosis $K$ from `metrics.moments`; VaR $= -(\hat\mu + \hat\sigma z_{cf})$ |
| Cornish–Fisher ES | $\frac{1}{1-\alpha}\int_\alpha^1 \text{VaR}_u\,du$, by numerical quadrature (SciPy) |
| Filtered historical simulation | volatility filter EWMA($\lambda$, required): $z_t = r_t/\hat\sigma_t$ with $\hat\sigma_t$ known at $t-1$; VaR and ES at $T+1$ are $\hat\sigma_{T+1}$ times the historical VaR and ES of $z$ (Hull–White 1998, Barone-Adesi et al. 1999) |

- **Cornish–Fisher limits:**
  - The expansion is a valid quantile function only if it increases in $z$ (Maillard 2012).
  - If it does not increase on the tail used, the function raises instead of returning a
    wrong number.
- **Filtered historical simulation:**
  - The filter is started from the sample variance of a required `warmup` number of returns.
    Those returns are not used as filtered observations.
  - A GARCH filter needs maximum-likelihood estimation; it is listed in `docs/IDEAS.md`.

## VaR backtesting

- **Forecasts:** `var_forecasts(returns, method, window, confidence)` produces, for each date
  $t$, a VaR from the `window` returns **before** $t$ only.
  - A test changes $r_t$ and checks that the forecast for $t$ does not move.
- **Hits:** $I_t = 1$ when the loss $-r_t$ is strictly greater than the VaR forecast for $t$.
  The forecasts and realised returns must share the same index.
- **Kupiec POF test:**
  - $LR_{pof} = -2\ln\frac{(1-p)^{n-x}p^x}{(1-\hat p)^{n-x}\hat p^x}$, with $p = 1-\alpha$ and
    $\hat p = x/n$, compared with $\chi^2(1)$;
  - $0 \ln 0 = 0$, so 0 or $n$ exceedances are valid inputs.
- **Christoffersen tests:**
  - The independence statistic $LR_{ind}$ uses the transition counts $n_{00}, n_{01}, n_{10},
    n_{11}$ and is compared with $\chi^2(1)$.
  - Conditional coverage is $LR_{cc} = LR_{pof} + LR_{ind}$, compared with $\chi^2(2)$.
  - A sequence with no exceedance, or with no transition out of an exceedance, has $LR_{ind} = 0$,
    with a note.
- **Output:** the number of exceedances, the expected number, the statistics and the p-values.
  The result says "the test does not reject", never "the model is correct".

## Edge cases

- **Data:**
  - empty input, a single observation, zero variance, a constant column;
  - more assets than observations: the sample covariance is singular, but Ledoit–Wolf still
    works;
  - NaN with each `missing` policy;
  - duplicated or unsorted index (raises, phase 1.1).
- **Weights:** weights summing to 0 (long-short); a zero-volatility portfolio (raises); labels
  that do not match the returns (raise).
- **Backtest:** 0 exceedances; all exceedances; forecasts and returns with different indexes.

## Risks

- **Estimation error.** Every estimate carries sampling error. `n_obs` is always reported, and
  the report states the window. Optimisation (4.x) must not use these estimates without
  shrinkage or constraints.
- **Non-normal tails.** The normal and Cornish–Fisher methods understate fat tails. The
  backtests make that visible, and no method is presented as "the" VaR.
- **Look-ahead in backtests.** Forecasts use only data before the forecast date. A dedicated
  test fails if any later return changes an earlier forecast.

## New dependencies

- **scikit-learn as a dev-only dependency**, used only in tests to cross-check Ledoit–Wolf
  against an independent implementation. The library never imports it.
- Nothing else is new (NumPy, SciPy and statsmodels are already used).
