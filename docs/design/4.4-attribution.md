# Design note — Phase 4.4 `qrlab.attribution`: performance attribution

Status: **approved 2026-11-12.** Deviations, if any, are listed at the end.

## Goal

Explain where the active return (portfolio minus benchmark) came from, in three ways that
always **add up exactly** to the active return:

- **Brinson–Fachler**, by segment: allocation, selection and interaction;
- **factor-based**: exposures times factor returns, plus alpha and residual;
- **currency**: local markets, currency moves and their cross term.

The phase completes M4. Attribution describes a result; it does not test whether the manager
was skilful. The factor version reports alpha with its standard error so that the two are not
confused.

## Inputs

- **Segments:** per period, portfolio and benchmark weights and returns by segment (for
  example sectors, asset classes or countries). Each input is a `DataFrame` (periods ×
  segments) on a validated index with no NaN.
  - The weights are start-of-period weights and must sum to 1 in each period. Cash is a
    segment if wanted.
  - The segment labels of the portfolio and the benchmark must match. A segment absent from one
    side has weight 0 there, and its return is then needed only on the side that holds it.
- **Factors:** a time series of active returns and factor returns on the same index; nothing is
  aligned silently.
- **Currency:** local returns and currency returns (the value of one unit of the currency in
  the base currency) per segment, together with the exposure currency of each segment.

## Definitions

**Brinson–Fachler (one period).** With benchmark total $R_b = \sum_s w_{b,s} r_{b,s}$:

| Effect | Formula |
|---|---|
| Allocation | $A_s = (w_{p,s} - w_{b,s})(r_{b,s} - R_b)$ |
| Selection | $S_s = w_{b,s}(r_{p,s} - r_{b,s})$ |
| Interaction | $I_s = (w_{p,s} - w_{b,s})(r_{p,s} - r_{b,s})$ |

- $\sum_s (A_s + S_s + I_s) = R_p - R_b$ exactly. Each period's attribution checks this
  identity to 1e-12.
- `interaction` is a required parameter: `"separate"`, or `"in_selection"`, which uses
  $S_s = w_{p,s}(r_{p,s} - r_{b,s})$.

**Several periods (Carino 1999 linking).**

- Arithmetic effects summed over periods do not equal the compounded active return
  $\prod(1+R_{p,t}) - \prod(1+R_{b,t})$.
- Each period's effects are therefore scaled by $k_t/K$, where
  $k_t = \dfrac{\ln(1+R_{p,t}) - \ln(1+R_{b,t})}{R_{p,t} - R_{b,t}}$ (or $1/(1+R_{p,t})$ when
  $R_{p,t} = R_{b,t}$), and $K$ is the same expression on the total returns.
- The linked effects sum exactly to $\prod(1+R_{p,t}) - \prod(1+R_{b,t})$.
- `linking` is a required parameter:
  - `"carino"`;
  - `"none"`, which reports the plain sums together with the residual against the compounded
    active return, so that the residual stays visible.

**Factor-based (ex post).**

- The active return is regressed on the factors with an intercept by OLS
  (`stats.ols`, with `cov_type` and `hac_lags` explicit): $a_t = \alpha + \beta^\top f_t + e_t$.
- **Contribution** of factor $k$ over the sample: $\beta_k \bar f_k$ per period, and
  $\beta_k \sum_t f_{k,t}$ cumulative (arithmetic).
- **Identity:** OLS with an intercept has residuals that sum to 0, so
  $\sum_t a_t = T\alpha + \sum_k \beta_k \sum_t f_{k,t}$ exactly.
- **Output:** $\alpha$ with its standard error and $t$-statistic, and $R^2$. A positive $\alpha$
  is labelled "not significant" unless its $|t| \ge 2$, and the docs explain that even then it
  is one test of many.

**Currency.**

- The base return of segment $s$ is $(1+\ell_s)(1+x_s) - 1$, where $\ell_s$ is its local
  return and $x_s$ the return of its currency.
- The portfolio's base return splits into:
  - local markets $\sum_s w_s \ell_s$;
  - currency $\sum_s w_s x_s$;
  - cross term $\sum_s w_s \ell_s x_s$.
- Active currency attribution compares this split for the portfolio and the benchmark. The
  three active parts sum to the active base return exactly.
- Forward premia and hedging costs (the full Karnosky–Singer model) need interest-rate data per
  currency; they are listed in `docs/IDEAS.md`.

## Output

`Attribution` holds:

- the effects per period and segment;
- the totals by segment and by effect;
- the linking method;
- the active return they explain and the residual (0 within 1e-12, or reported with
  `linking="none"`).

`FactorAttribution` holds the betas, alpha with inference, the contributions and the residual.
`CurrencyAttribution` holds the local, currency and cross parts, for the portfolio, the
benchmark and their difference.

## Edge cases

- **Inputs:** weights that do not sum to 1 (raise); mismatched indexes or labels (raise); a
  single period, where linking leaves the effects unchanged.
- **Linking:** $R_{p,t} = R_{b,t}$ uses the limit formula; a total return of −100 % or below
  raises, because the logarithm is undefined.
- **Factors:** fewer observations than the number of factors plus 2 raises, as in
  `stats.ols`.

## Risks

- **Choice of segments and benchmark** drives the story. Both are explicit inputs and are shown
  in the output.
- **Linking is a convention**, not a truth. Carino is one of several methods. The method is
  always reported, and `"none"` shows the raw residual.
- **Alpha is not skill.** It carries its standard error and the multiple-testing caveat.
