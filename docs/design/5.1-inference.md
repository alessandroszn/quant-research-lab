# Design note — Phase 5.1: inference for research results

Status: **approved 2026-11-12.** Deviations, if any, are listed at the end.

## Goal

The statistics the studies (5.3) need before any claim:

- corrections for testing many hypotheses;
- the probabilistic and deflated Sharpe ratios, which account for non-normal returns and for
  the number of strategies tried;
- tests of the difference between two Sharpe ratios;
- bootstrap confidence intervals for that difference.

Every function returns the statistic **with its assumptions**, such as i.i.d. or the HAC lags,
and the docs say what a "not rejected" result does and does not mean.

## Where it lives

- `stats.multiple_testing`: p-value corrections. They are pure functions of p-values, so they
  sit in layer 2.
- `metrics.sharpe_inference`: PSR, DSR, Sharpe-difference tests and the bootstrap interval.
  `metrics` already imports `stats` and has the Sharpe ratio and the moments.
- The layering does not change.

## Multiple testing (`stats.multiple_testing`)

| Method | Adjusted p-values (sorted $p_{(1)} \le \dots \le p_{(m)}$) | Controls |
|---|---|---|
| Holm (1979) | $\tilde p_{(i)} = \max_{j \le i} \min\{1, (m-j+1)\,p_{(j)}\}$ | family-wise error rate, any dependence |
| Benjamini–Hochberg (1995) | $\tilde p_{(i)} = \min_{j \ge i} \min\{1, m\,p_{(j)}/j\}$ | false discovery rate, independence or positive dependence |
| Benjamini–Yekutieli (2001) | BH multiplied by $c(m) = \sum_{k=1}^m 1/k$ | false discovery rate, any dependence |

- **Inputs:** p-values in [0, 1] with labels, and $\alpha$. The `method` and $\alpha$ are
  required.
- **Output:** the adjusted p-values in the input order, the rejection flags, $m$, the method and
  $\alpha$.
- Every method is cross-checked against `statsmodels.stats.multitest.multipletests`.

## Sharpe-ratio inference (`metrics.sharpe_inference`)

All Sharpe ratios here are **per period**, not annualised, as in the papers. The annualised
value is reported alongside with an explicit `periods_per_year`. Skewness $\gamma_3$ and
kurtosis $\gamma_4$ (not excess) come from `metrics.moments` (bias-corrected).

- **Probabilistic Sharpe ratio** (Bailey and López de Prado 2012):
  $\mathrm{PSR}(SR^*) = \Phi\!\left(\dfrac{(\widehat{SR} - SR^*)\sqrt{T-1}}
  {\sqrt{1 - \gamma_3\widehat{SR} + \frac{\gamma_4 - 1}{4}\widehat{SR}^2}}\right)$.
  This is the probability that the true Sharpe ratio exceeds the benchmark $SR^*$, which is
  required.
- **Deflated Sharpe ratio** (Bailey and López de Prado 2014): $\mathrm{PSR}(SR^*_0)$ with
  $SR^*_0 = \sqrt{V}\,[(1-\gamma)\Phi^{-1}(1 - 1/N) + \gamma\,\Phi^{-1}(1 - 1/(Ne))]$.
  - $N \ge 2$ is the number of independent trials.
  - $V$ is the variance of the trials' Sharpe ratios.
  - $\gamma$ is the Euler–Mascheroni constant.
  - The inputs are $N$ and either the trials' Sharpe ratios ($V$ estimated, `ddof=1`) or an
    explicit $V$. Choosing $N$ is the user's responsibility: the docs explain that correlated
    trials count as fewer independent ones.
- **Jobson–Korkie test with Memmel's (2003) correction:**
  $z = (\widehat{SR}_1 - \widehat{SR}_2)/\sqrt{\theta}$, with
  $\theta = \frac1T[2 - 2\rho + \frac12(SR_1^2 + SR_2^2 - 2SR_1SR_2\rho^2)]$.
  - It assumes i.i.d. normal returns, and the result says so.
  - The two series must share the index.
- **Ledoit–Wolf (2008) HAC test.** The difference has a delta-method standard error from the
  HAC covariance (Bartlett kernel, explicit `hac_lags`) of the first and second moments of both
  series. It is robust to fat tails and autocorrelation. With `hac_lags = 0` it is the i.i.d.
  version without normality.
- **Bootstrap interval for the difference.** A stationary-bootstrap percentile interval reuses
  `stats.stationary_bootstrap`, with an explicit mean block length, number of resamples and
  `rng`.

| Holm, $p$ = (0.01, 0.04, 0.03, 0.005) | adjusted (0.03, 0.06, 0.06, 0.02); at 5 % the first and fourth are rejected; equals statsmodels |
| BH, same $p$ | adjusted (0.02, 0.04, 0.04, 0.02); all four rejected at 5 %; equals statsmodels |
| BY, same $p$ | BH times $c(4)$ = 2.0833, capped at 1; equals statsmodels `fdr_by` |
| PSR: $\widehat{SR}$ = 0.1 a month, $T$ = 120, $\gamma_3$ = 0, $\gamma_4$ = 3, $SR^*$ = 0 | $z = 0.1\sqrt{119}/\sqrt{1.005}$ = 1.088154; PSR = 0.861736 |
| DSR: $N$ = 100 trials, $V$ = 0.01 | $SR^*_0$ = 0.253060; a strategy with $\widehat{SR}$ = 0.3 ($\gamma_3$ = 0, $\gamma_4$ = 3, $T$ = 120): $z$ = 0.500905, DSR = 0.691781 |
| Jobson–Korkie–Memmel: $SR$ = 0.2 and 0.1, $\rho$ = 0.5, $T$ = 120 | $\theta$ = 0.0085, $z$ = 1.084652, two-sided $p$ = 0.278076 |
| Two identical series | difference 0; JKM and HAC raise, because the variance of the difference is zero, and the message says so |
| Size, simulated | under equal true Sharpe ratios (seeded), both tests reject at 5 % in a rate within 3 standard errors of 5 % over 2,000 replications |
| Bootstrap | the interval contains the sample difference, and the same seed gives the same interval |

## Edge cases

- **Multiple testing:** p-values outside [0, 1], NaN or none at all (raise); a single
  hypothesis (no adjustment).
- **PSR and DSR:**
  - $T < 3$ raises;
  - a negative value under the square root (possible for extreme skewness) raises, with the
    moments shown;
  - $N < 2$ raises.
- **Sharpe-difference tests:** different indexes (raise); zero variance (raises).

## Risks

- **"Not significant" is not "no effect".** Results report the estimate, the interval and the
  p-value, never only a flag.
- **The number of trials in the DSR** is easy to understate. The experiment runner (5.2)
  records every configuration tried and passes the count.
- **Normality assumptions.** JKM assumes them, while HAC and the bootstrap do not; the studies
  use HAC or the bootstrap.

## New dependencies

None. statsmodels and SciPy are already used.

## Effort

15–20 h (roadmap). One PR: both modules, the hand and statsmodels cross-check tests, the
simulated size test, and docs.

## Deviations from the approved note

- **Pure functions alongside the data functions.** Besides the functions that take return
  series, `probabilistic_sharpe`, `expected_max_sharpe` and `jkm_statistic` take the summary
  numbers directly (Sharpe ratio, moments, $N$, $V$, $ho$). The hand examples test those, and
  studies can use them when only summaries are available.
- **Sharpe estimators.** The Ledoit–Wolf HAC test uses the `ddof=0` variance, as in the paper.
  JKM, PSR and the bootstrap use `ddof=1`. Each result states its method.
- **Identical series.** For two identical series, JKM and HAC both raise "zero variance", as
  the note planned.
